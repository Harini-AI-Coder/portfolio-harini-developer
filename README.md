# portfolio-harini-developer

This repository has been scaffolded into a React + Vite project for a developer portfolio.

## Run locally

1. Install Node.js (LTS) if you don't have it. Download from https://nodejs.org/ or use nvm-windows.

2. In a terminal at the project root run:

```
npm install
npm run dev
```

Open the local dev URL printed by Vite (usually http://localhost:5173).
